# DhanyaMart

DhanyaMart is an e-commerce web application developed using Spring Boot, Java, HTML, CSS, JavaScript and MySQL.

## Features

- User Login
- Product Management
- Product Listing
- Shopping Cart
- Order Management
- Product Reviews
- Admin Dashboard
- Admin Order Management
- Admin Review Management

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS
- JavaScript
- MySQL
- Maven
- GitHub
