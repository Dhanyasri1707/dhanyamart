# DhanyaMart

DhanyaMart is an e-commerce web application developed as a college capstone project.

The application allows users to view products, add products to a shopping cart, place orders, and submit product reviews. An administrator can manage products, view orders, and manage customer reviews.

## Features

- User Login
- Product Listing
- Product Management
- Shopping Cart
- Cart Quantity and Total Calculation
- Order Placement
- Order Management
- Product Reviews
- Admin Dashboard
- Admin Product Management
- Admin Order Management
- Admin Review Management

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS
- JavaScript
- MySQL
- Maven
- Git
- GitHub

## Project Structure

The project follows a Spring Boot application structure.

- `src/main/java` - Java source code
- `src/main/resources/templates` - HTML/Thymeleaf pages
- `src/main/resources/static` - CSS, JavaScript and static resources
- `application.properties` - Application and database configuration
- `pom.xml` - Maven project configuration

## Database

DhanyaMart uses MySQL as the database.

The main database is:

`dhanyamart`

The application stores information related to users, products, shopping cart items, orders and reviews.

## Project Setup

1. Install Java and MySQL.
2. Create the `dhanyamart` database in MySQL.
3. Configure the database details in `application.properties`.
4. Open the project in Visual Studio Code or another Java IDE.
5. Run the Spring Boot application using Maven.
6. Open the application in a web browser.
